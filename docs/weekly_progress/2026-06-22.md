## Slides 3–5 — Reconstruction versus generation

Reconstruction strengths:

- genuinely navigable;
- faithful to the real scene.

Reconstruction weaknesses:

- heavy input requirements;
- high computation time.

Generation strengths:

- minimal input;
- lower computation time;
- can imagine unseen regions.

Generation weaknesses:

- weak global coherence;
- artifacts grow far from the original viewpoint.
